# Hospital Management System

A practical **MySQL relational database project** for managing hospital operations such as patients, doctors, appointments, treatments, and billing.

> **Status:** Learning / portfolio project built to strengthen SQL, relational database design, data integrity, and analytical querying.

## Objective

The project models common hospital workflows and answers practical questions such as:

- Which doctors handle the most appointments?
- What is the revenue generated by each department?
- Which patients have upcoming appointments?
- What are the most common diagnoses?
- Which bills remain unpaid?

## Tech Stack

- **MySQL**
- **SQL**
- Relational database design
- Joins, subqueries, CTEs, views, aggregations

## Database Design

Main entities:

- `departments`
- `doctors`
- `patients`
- `appointments`
- `treatments`
- `bills`

Relationships are implemented using **primary keys** and **foreign keys** to maintain data integrity.

## How to Run

1. Open MySQL Workbench or another MySQL client.
2. Run `sql/schema.sql`.
3. Run `sql/sample_data.sql`.
4. Execute queries from `sql/queries.sql`.
5. Optionally create reporting views using `sql/views.sql`.
